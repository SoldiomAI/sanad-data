# بيانات منصة سَنَد · SANAD Data

هذا المستودع يحوي **البيانات المنشورة** لمنصة سَنَد — ملفات JSON والوسائط التي تعرضها الصفحة، تُحدَّث آليًّا من خطِّ الإنتاج كلَّ نصفِ ساعةٍ تقريبًا.

🔗 المنصة: https://isnad.news · https://sanad-sovereign-news-intelligence.netlify.app

## الملفات الحيّة (`daily/`)

| الملف | المحتوى |
|---|---|
| `news.json` | الأخبار المُسنَدة بأقسامها ودرجاتها (صحيح / حسن / ضعيف الإسناد) |
| `latest.json` | نشرة اليوم: النص والصوت (والفيديو إن اكتمل فيديو اليوم نفسه) |
| `bulletin-YYYY-MM-DD.mp3` | صوت النشرات — يُحتفَظ هنا بآخر ٣٠ يومًا |
| `official.json` | البيانات الرسمية من وكالات الأنباء الحكومية |
| `alerts.json` | تحذيرات الجهات الرسمية وتوجيهاتها |
| `rumors.json` | أحكام الشائعات بمصادرها وبوّابات فحصها |
| `papers.json` | 📚 الورّاق: أحدث أوراق الذكاء الاصطناعي (arXiv / Hugging Face) بملخّص عربيّ |
| `tension.json` | مؤشّر عدم الاستقرار الإقليمي المحسوب |
| `forecast.json` | الاستقراء: سيناريوهات مبنية على السوابق |
| `map.json` | خريطة الأخبار حسب الدول |
| `osint.json` | إشارات ميدانية مفتوحة (زلازل / طيران / حرائق) منسوبة لمصدرها |
| `wave.json` · `waves.json` | موجات الأخبار المتتبَّعة |
| `column.json` · `columns/` | عمود المُدوِّن اليومي وأرشيفه |
| `analyst.json` | قراءة المُحلِّل الصوتية |
| `agents.json` · `agents_dynamic.json` | طبقة الوكلاء وحالتهم الحيّة |
| `correspondents.json` | مراسلو الدول وذاكرتهم |
| `health.json` | حالة كل قسم بصدق: fresh / stale / empty / dead / dormant |
| `cost.json` | شفافية الإنفاق اليومي على النداءات المدفوعة |
| `bundle.json` | كل ملفات العرض في ملف واحد (الطلب الأخف للواجهات) |
| `archive/` | لقطات الجولات السابقة + `index.json` |
| `social/` | حزم النشر الاجتماعي اليومية |

### أقسام مُعطَّلة عمدًا
`intel.json` (حصيلة الأزمة) و`verify.json` (المطابقة المستقلة) مُعلَّقان — مبدأ المنصة:
**لا رقم بلا إسناد**، فلا تُنشَر حصيلة حتى تتوفّر أرقام رسمية قابلة للتحقّق.
حالتهما تُعلَن «dormant» بصدقٍ في `health.json`.

## منهج الإسناد

كل خبر يحمل درجة محسوبة من خمسة معايير معلنة: الاتصال، عدالة المصدر، الضبط،
عدم الشذوذ، انتفاء العلة — التفاصيل في `llms.txt` على الموقع.
